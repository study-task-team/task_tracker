# Реестр технического долга

| № | Описание | Причина | Критичность | План устранения |
|---|---|---|---|---|
| 1 | База данных SQLite | В MVP выбрана для простоты развертывания. При конкурентной записи блокирует всю базу. | Средняя | В ЛР4 перейти на PostgreSQL или добавить WAL-режим. |
| 2 | Отсутствие пагинации | Если задач станет больше 100, страница будет грузиться долго. | Низкая | Добавить пагинацию в следующей итерации. |
| 3 | Имитация авторизации | Роли хранятся в куках без шифрования. | Низкая | В Post-MVP внедрить JWT. |

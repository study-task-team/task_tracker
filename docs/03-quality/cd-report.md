# Отчёт о непрерывной доставке (CD)

## Выбранное решение
Для автоматического деплоя выбран сервис **Render.com**.
Причина выбора: нативная поддержка Docker, бесплатный тариф, автоматическое обновление при пуше.

## Конфигурация
Создан файл `render.yaml` (Infrastructure as Code). 
В `src/db.py` добавлена поддержка переменной `DATABASE_URL`, чтобы база данных корректно сохранялась в контейнере.

# Видение продукта

## Цель
Создать веб-сервис для управления учебными курсами и заданиями, разделенный на две роли: Студент и Преподаватель.

## Целевые пользователи
1. **Студент** — видит назначенные ему курсы, следит за дедлайнами, отмечает статус выполнения заданий.
2. **Преподаватель** — создает курсы, добавляет в них задания с дедлайнами, отслеживает успеваемость студентов.

## Проблема
Студенты теряют дедлайны, разбросанные по разным чатам. Преподавателям сложно централизованно выдавать задания и видеть, кто и что сдал.

## Ключевые сценарии
**Студент:**
- Входит в систему под своей ролью.
- Видит дашборд с ближайшими дедлайнами.
- Меняет статус задания (К выполнению -> В работе -> Сдано).

**Преподаватель:**
- Входит в систему под своей ролью.
- Создает новый курс.
- Добавляет задания в курс, указывая дедлайн.
- Видит таблицу успеваемости (кто сдал, кто нет).

## Критерии успеха (измеримые)
- **K1.** Разграничение прав: студент не может создавать курсы, преподаватель не может менять статус задания.
- **K2.** Навигация между ролями интуитивно понятна.
- **K3.** Сервис стабильно работает и развернут в облаке.

## Что НЕ входит в продукт (вне MVP)
- Полноценная авторизация с паролями (JWT, OAuth) — используем имитацию входа для демонстрации ролей.
- Интеграция с внешними LMS (Moodle и т.д.).
- Push-уведомления.

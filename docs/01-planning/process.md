# Процесс команды

## Методология
Kanban. Работа ведется в едином потоке, что позволяет параллельно вести бэкенд и тесты.

## Доска задач (WIP-лимиты)
- Бэклог (без лимита).
- Готово к работе.
- В работе (лимит: 2 — по одному на разработчика).
- Ревью (лимит: 1 — чтобы не скапливались PR).
- Готово.

## Definition of Ready
- Есть критерии приемки.
- Оценена в Story Points.

## Definition of Done
- Код в `main`.
- CI зеленый (линтер + 95% покрытие).
- Проведено перекрестное ревью.
- Задеплоено на Render.

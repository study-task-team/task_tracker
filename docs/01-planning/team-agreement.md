# Рабочее соглашение команды

**Команда:** Язев И.В., Сефербеков Д.С.  **Проект:** Трекер учебных задач

## Ритм и синхронизация
- Время синхронизации: ежедневно по 10 минут в чате.
- Каналы связи: Telegram (чат команды), GitHub Issues (для фиксации задач), GitHub Projects (для ведения доски).

## Работа с задачами
- Методология: Kanban (непрерывный поток задач).
- WIP-лимиты: «В работе» ≤ 2 (по одному на человека), «Ревью» ≤ 1.
- Задача двигается по доске в момент фактической смены состояния.
- Definition of Ready: Задача имеет четкое описание, критерии приемки (Дано/Когда/Тогда), оценку в Story Points.
- Definition of Done: Код в `main` через PR, CI зеленый (покрытие ≥ 95%), проведено код-ревью, сервис задеплоен.

## Код и ревью
- Ветвление: `main` + ветки `feature/<issue-id>-<slug>` (GitHub Flow).
- Формат сообщений коммита: Conventional Commits (feat, fix, docs, chore).
- Каждое изменение проходит перекрестное ревью (Участник А проверяет код Участника Б, и наоборот).
- Разногласия: при конфликте приоритетов решение принимается по значениям WSJF и критериям приёмки.

# Карта пользовательских историй

## Шаги пользовательского пути
Горизонтальная ось отражает путь пользователя в системе. 
Так как у нас две роли, путь разделен на две дорожки (Swimlanes).

1. **Авторизация:** Вход в систему.
2. **Курсы:** Просмотр списка, создание, удаление.
3. **Задания:** Создание, просмотр списка, редактирование.
4. **Действия с заданиями:** Смена статуса, фильтрация.
5. **Анализ:** Просмотр статистики и дашборда с дедлайнами.

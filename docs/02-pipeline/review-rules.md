# Правила ревью

## Обязательные требования
1. Каждый Pull Request должен быть проверен вторым участником команды.
2. Никто не может мержить свой PR без Approve (настроено в Branch protection).
3. Размер PR не должен превышать 300 строк изменений.
4. Ревью проводится в течение 24 часов с момента создания PR.

## Чек-лист для ревьюера
- [ ] Код решает задачу из Issue.
- [ ] CI (GitHub Actions) зеленый.
- [ ] Нет мусора (базы данных, папки .idea).
- [ ] Критерии приемки выполнены.

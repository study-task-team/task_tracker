# Отчёт об оптимизации конвейера

## Что настроено
- **CI (GitHub Actions):** запускается при каждом Push и Pull Request в ветку `main`.
- **Шаги CI:**
  1. Установка Python 3.11.
  2. Установка зависимостей (`requirements-dev.txt`).
  3. Линтер Ruff.
  4. Тесты Pytest с проверкой покрытия (порог 95%).
- **Docker:** приложение собирается в контейнер `python:3.11-slim`, запуск через `docker-compose`.

## Оптимизация
- Добавлен кэш `pip` в CI (сократило время сборки с 1 минуты до 20 секунд).
- В Dockerfile зависимости копируются до кода (использование кэша слоев).

## Результаты
- Время выполнения CI: ~15-20 секунд.
- Покрытие тестами: 100%.

# Документация ЛР1: Планирование

В этой папке собраны артефакты первого этапа проекта.

- `vision.md` — видение продукта, пользователи и границы.
- `story-map.md` — карта пользовательских историй (Студент и Преподаватель).
- `backlog.md` — 13 историй с критериями приёмки (Дано/Когда/Тогда).
- `estimates.md` — оценки в Story Points и PERT.
- `prioritization.md` — WSJF и формальная модель выбора релиза.
- `release-plan.md` — сетевой график, критический путь и Монте-Карло.
- `process.md` — методология Kanban, WIP-лимиты, DoR/DoD.
- `team-agreement.md` — рабочее соглашение команды.
